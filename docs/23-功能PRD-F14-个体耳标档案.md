# 功能 PRD — F14 个体耳标档案

> 版本 V1.0 · 2026-10-14 · mock 层纵切实现（storage v10）
> 关联：02-数据库（animal_individual 表）、03-API（十六节）、F02 存栏流水、F07 生命周期/出栏

## 一、背景与目标

平台现有存栏以**圈舍批次**为口径（快照由 stock_change 流水驱动），只能回答"这个圈有多少头"，
回答不了"这一头是谁"。养殖现场对牛羊猪等大牲畜普遍佩戴电子耳标，用户要求：
**每只动物都有耳标，能录入耳标信息，把管理精度从"圈"落到"个体"**。

目标：新增个体耳标档案（F14），耳标号场内唯一，随存栏流水自动增减/迁移，账实强关联对账。

## 二、关键决策（用户拍板）

| 决策点 | 结论 |
| --- | --- |
| 与存栏的关系 | **强关联对账**：在栏个体数必须等于圈舍存栏快照；入栏/离栏/转群必须携带耳标 |
| 录入方式 | **单个 + 批量**（连号生成） |
| 存栏纪律 | 不变：快照仍只由 stock_change 流水驱动，个体表随流水联动，绝不直接改存栏 |

## 三、功能需求

### FR-01 档案与列表
- 字段：耳标号（场内唯一，1~32 位不含空格）、性别（公/母）、圈舍、品种（建档时继承圈舍品种）、
  出生日期（选填）、来源、状态（在栏 active / 已出栏 sold / 已死淘 dead / 已调减 removed）、
  离栏说明与时间、备注、建档时间。
- 列表支持圈舍 / 状态 / 关键词（耳标号、备注、来源）筛选与分页。
- 边界：耳标是终身身份，**场内唯一含全部状态个体**（含已离栏），复用即破坏追溯链。

### FR-02 录入耳标（单个 / 批量）
- **单个建档**：仅允许在"差额头寸"内补录（该性别在栏个体 < 快照数），即只收敛历史差额；
  新入栏动物一律走「调整存栏」流水（FR-04）。
- **批量建档**：同圈同性别连号（前缀-M/F+3 位序号，如 P1-M016），逐个建档逐个校验头寸，
  任一失败即止、已建部分有效（断点续建）。

### FR-03 编辑与纠错删档
- 档案信息（耳标号/出生日期/来源/备注）可改；性别与圈舍归属不可改（转群走流水）。
- 纠错删档仅限**在栏**个体（录错号场景）；已离栏个体为历史档案，不可删。

### FR-04 存栏流水强关联（核心）
| 流水 | 耳标要求 |
| --- | --- |
| 入栏类（产仔/购入/手动调增） | 必带 `male_tags` / `female_tags`，数量与公母增量一致、场内未占用；入栏即建档 |
| 离栏类（死淘/出栏/手动调减） | 必带 `exit_tag_nos`，从本圈在栏个体中勾选，公母分布与数量一致；离栏即置状态 |
| 转群 | 必带 `tag_nos`（源圈在栏），两笔流水后个体迁移到目标圈（状态不变） |
| 出栏（F07） | 部分出栏必须选耳标；**整栏出栏自动清档**（全部在栏个体离栏） |

- 一致性：耳标校验全部前置，任一失败不写流水不建档（等效回滚）。
- 出栏个体离栏说明自动带去向与强制出栏标记。

### FR-05 对账与一键补齐
- 对账口径：`diff = 圈舍存栏快照 − 在栏个体数`，逐圈与全场两级展示。
- 正常流水下 diff 恒为 0；**diff > 0 仅出现在历史未建档数据**（F14 上线前的存量圈）。
- 「一键补齐」：按性别头寸自动生成耳标（默认前缀 `P{penId}`，序号自动避让已占用号），
  只建个体档案不动存栏，台账留痕（record_type=individual）；幂等，可反复执行。

### FR-06 自动建档场景
- 建圈初始存栏：自动生成（来源=初始建档）。
- F07 分娩事件：活仔出生即自动建档（来源=分娩自动建档，档案页可改为实际耳标号）。
- F07 淘汰（cull）：优先按母畜耳标号精确匹配离栏；无对应档案时同性别 FIFO 兜底，保证账实不脱钩。
- 演示种子（F07/F12）同步适配，载入即账实一致。

## 四、异常与文案

| 场景 | 码 | 文案要点 |
| --- | --- | --- |
| 耳标格式非法 | 42201 | 1~32 位且不含空格 |
| 耳标已存在（场内） | 42201 | 耳标号 X 已存在（场内唯一） |
| 无头寸建档 | 42201 | 提示走「调整存栏」流水 |
| 入栏未带标 / 数量不符 | 42201 | 请填写与数量一致的耳标（公 X 个、母 Y 个） |
| 离栏分布不符 | 42201 | 公母分布与数量不符 |
| 部分出栏未选标 | 42201 | 部分出栏需选择出栏耳标（精确到个体） |
| 整栏出栏但耳标数≠存栏 | 40002 | 请先在「个体耳标」页一键补齐后再出栏 |
| 他人圈舍 | 40302 / 40401 | 与既有越权口径一致 |

## 六、页面与入口

- 新增「个体耳标」页（/individuals，生产管理组）：对账横幅（差额圈一键补齐）+ 档案表 +
  录入耳标弹窗（单个/批量页签）+ 编辑/纠错删档。
- 场舍管理「调整存栏」弹窗：入栏类型加耳标录入（逐行 + 按序生成），离栏类型加在栏个体勾选。
- 场舍管理「转群」弹窗：源圈在栏个体勾选。
- 出栏登记页步骤 2：部分出栏勾选耳标，整栏出栏提示自动清档。

## 七、边界与遗留

- 母畜档案（F07）为独立台账，不与个体耳标表联动（避免耳标唯一性口径冲突）；母猪圈差额用补齐收敛。
- 禽类等大批量动物不适合逐只建档——强关联为用户明确选择，实际使用中可用"批量建档+连号"降低成本；
  后续如需放开，可加"圈舍级免建档"白名单（版本池）。
- 个体级体重/用药追溯（按耳标查生长曲线、用药史）列入版本池，V1.0 不做。
