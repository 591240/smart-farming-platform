## 一、设计语言：「现代田园 · Refined Agritech」

一句话定义：**用精密仪器的排版精度，承载田园牧歌的色彩气质。**

高级感来自四个字：**克制、细节**。我们不堆装饰——不放大阴影、不搞彩色渐变、不堆图标；我们把预算全部花在别人看不见的地方：对齐、间距、字重、光影层次、动效曲线。最终呈现的状态是：第一眼"清爽舒服"，用三分钟"处处顺手"，细看"每处都讲究"。

### 1.1 五条设计原则

1. **装饰做减法，细节做加法**：页面上的每种视觉手段（色、线、影、动效）最多只承担一个职责；去掉任何元素页面依然成立，才算合格
2. **层次靠光影，不靠线框**：卡片与底色的分离主要靠柔和阴影和极低对比描边完成，禁用粗边框、禁用深色分割线
3. **数字是主角**：养殖户看的是"多少头、多少度、多少钱"——所有数据值用等宽数字（tabular-nums）、加大字号、加重字重，标签让位
4. **自然色彩系统**：农业绿作为唯一品牌主色贯穿全站；辅助色只从自然物中取（晴空蓝、晨光橙、告警红），饱和度统一压低一档，避免"塑料感"
5. **动效有生命，但无声**：所有动效服务于"确认操作发生"与"引导视线"，一律 ≤300ms、统一缓动曲线；没有弹跳、没有闪烁、没有纯炫技的动画

### 1.2 高级感反模式清单（实现时禁用）

| 禁用项 | 原因 |
|--------|------|
| 紫色/蓝紫渐变、彩虹渐变 | 与农业绿品牌冲突，且是"AI 模板感"重灾区 |
| 阴影堆叠超过体系内三级 | 阴影失去层级意义，页面变"脏" |
| 圆角 >16px 的卡片、胶囊滥用 | 过圆显得玩具化，失去工具感 |
| 一页超过 2 种强调色 | 颜色失去语义，用户无从判断轻重 |
| 纯灰大色块底 + 纯白卡片硬拼 | 缺少色温过渡，"Excel 感" |
| 字重混用超过 3 档、同一页面字号超过 7 档 | 排版失去节奏 |
| 动效时长 >300ms 或带弹跳（bounce） | 工具产品动效要快、稳、准 |
| 深色粗边框框住一切 | 线框是层次的下策（见原则 2） |
| 图标风格混用（线性 + 面性混排） | 图标必须同一族、同一粗细 |

## 二、设计令牌（Design Tokens）

> 所有令牌用语义命名，为将来暗色模式预留结构。实现时以 CSS 变量/主题变量落地，禁止硬编码色值。
>
> **暗色模式决策：V1.0 明确不做。** 语义令牌结构已预留，后续若立项只需增补一组暗色变量值，组件代码零改动；在此之前任何页面禁止私自引入深色底，避免"半暗不暗"的失控状态。

### 2.1 色彩

**品牌主色（农业绿）— 完整色阶**

| Token | 值 | 用途 |
|-------|-----|------|
| primary-50 | `#F0FAF5` | 极浅底：选中行、标签底 |
| primary-100 | `#E6F5EE` | 浅底：选中背景、hover 底 |
| primary-200 | `#C9E8D8` | 边框强调、进度条底 |
| primary-500 | `#2E9E6B` | **主色**：主按钮、选中态、链接、图表主系列 |
| primary-600 | `#26895C` | hover |
| primary-700 | `#1F7A50` | 按压/深色文字（primary-dark） |
| primary-900 | `#145237` | 渐变深端、看板氛围带 |

**中性色 — 11 阶微暖灰（带 1° 绿色温，消除"Excel 感"）**

| Token | 值 | 用途 |
|-------|-----|------|
| bg-page | `#F7F8F6` | 页面背景（微暖灰白） |
| bg-card | `#FFFFFF` | 卡片/面板 |
| bg-subtle | `#F2F4F1` | 次级底（表头、分块、代码块） |
| bg-inset | `#EDEFEB` | 内嵌区域、滚动条槽 |
| border | `#E7E9E4` | 卡片描边（1px，低对比） |
| border-strong | `#D5D8D1` | 控件描边（输入框、按钮） |
| text-primary | `#1E2420` | 主文字（比纯黑柔和，带绿温） |
| text-secondary | `#5F6B62` | 次级文字、说明 |
| text-tertiary | `#8C958E` | 占位符、辅助 |
| text-disabled | `#B4BAB3` | 禁用 |
| overlay | `rgba(20, 30, 24, 0.45)` | 弹窗遮罩（微绿黑，非纯黑） |

**功能色（全站语义固定）**

| Token | 值 | 用途 |
|-------|-----|------|
| success | `#2E9E6B` | 与主色同源：正常、达标、在线 |
| warning | `#E8A23D` | mid 级告警、提醒（晨光橙，比传统琥珀更柔） |
| danger | `#D9534F` | high 级告警、休药期拦截（陶土红，沉稳不刺眼） |
| info | `#5B8DEF` | 中性提示（晴空蓝） |
| chart-2 | `#5B8DEF` | 图表次系列（湿度等） |
| chart-3 | `#E8A23D` | 图表第三系列（NH₃ 等） |
| chart-standard | `#C4CAD3` | 虚线参考线（品种标准、7 天均值） |

> 风险等级语义色固定：**low=success 绿 / mid=warning 橙 / high=danger 红**，全站统一且必须同时带文字标签（无障碍）。

### 2.2 字体

| 项 | 规格 |
|----|------|
| 字体族 | 中文 system-ui / PingFang SC / Microsoft YaHei；**数字与英文定稿 Inter**（开启 `tnum` 等宽数字特性），系统兜底 Segoe UI / Roboto；不加载中文网络字体（体积不划算），西文 `font-display: swap` 不阻塞首屏 |
| 字号阶梯 | 12 / 13 / 14 / 16 / 20 / 24 / 32 / 40（一页可见字号 ≤7 档） |
| 字重 | 400 正文 / 500 强调 / 600 标题（**禁用 700 以上**，高级感靠字号与留白，不靠加粗） |
| 页面标题 | 20px / 600 / 行高 1.4 |
| 卡片标题 | 16px / 600 |
| 正文 | 14px / 400 / 行高 1.7 |
| 辅助说明 | 12px / text-tertiary |
| **看板指标大数字** | 40px / 600 / `font-variant-numeric: tabular-nums` / 行高 1.1，单位用 14px / text-secondary 跟随其后 |
| 表格数字列 | tabular-nums，右对齐 |

### 2.3 布局、间距与圆角

| 项 | 规格 |
|----|------|
| 栅格 | **8pt 间距栅格**：所有间距取 8 的倍数（8/16/24/32/40）；紧凑场景允许 4 |
| 侧边导航 | 宽 232px，白底，无边框（以 1px 投影分离）；选中项 primary-100 底 + primary-700 文字 + 左缘 3px 主色圆角短条 |
| 顶部栏 | 高 60px，白底 + 1px 投影，含养殖场切换、告警铃铛（红点数）、用户头像 |
| 内容区 | 左右留白 32px（≥1440px 时 40px），卡片间距 16px |
| 卡片 | 圆角 12px + e1 阴影；内边距 24px（紧凑 16px） |
| 按钮圆角 | 10px；输入控件 10px；标签/徽标 6px；弹窗 16px |
| 表格 | 无竖线；表头 bg-subtle 底、12px/500；行高 48px；**斑马纹取消，改行 hover 底色过渡**（primary-50 @ 40%） |

**响应式断点表**（桌面优先，逐级降级、禁止错乱重排）：

| 断点 | 布局行为 |
|------|---------|
| ≥1440px | 内容区左右留白 40px；看板指标卡 4 列 |
| 1280~1439px | 留白 32px；指标卡 4 列；双栏保持 2/3 + 1/3（默认设计基准） |
| 1024~1279px | 指标卡降 2×2；看板/对话双栏改上下堆叠；表格横向滚动（首列与操作列冻结） |
| 768~1023px | 侧边栏收窄为图标栏（72px，hover 浮层展开）；指标卡 2×2 |
| <768px | 侧边栏隐藏（汉堡按钮 + 抽屉）；看板与对话页降级单栏；表格转卡片列表 |

### 2.4 阴影与层次体系（elevation）

三级阴影，全站只用这三级，多层柔和公式（环境光 + 主光）：

| 层级 | 值 | 用途 |
|------|-----|------|
| e0 无影 | — | 页面底、内嵌块 |
| **e1 卡片** | `0 1px 2px rgba(30,36,32,.04), 0 4px 12px rgba(30,36,32,.04)` | 所有卡片、表格容器 |
| **e2 弹层** | `0 2px 6px rgba(30,36,32,.06), 0 12px 32px rgba(30,36,32,.10)` | 下拉菜单、Popover、悬浮卡 |
| **e3 模态** | `0 4px 12px rgba(30,36,32,.08), 0 24px 64px rgba(30,36,32,.16)` | 弹窗、抽屉 |

- **hover 抬升**：可点击卡片 hover 时 `transform: translateY(-2px)` + e1→e2 阴影过渡（200ms），松开回落——这是"可点"的通用暗示
- 顶部栏/侧边导航用 **1px 极淡投影** `0 1px 0 rgba(30,36,32,.04)` 代替边框
- 可选微质感：卡片顶部 1px 内高光 `inset 0 1px 0 rgba(255,255,255,.6)`，增强"瓷面感"（白卡上几乎不可见，只在阴影上留层次）

### 2.5 动效令牌

| 令牌 | 值 | 用途 |
|------|-----|------|
| duration-fast | 120ms | hover 色彩过渡、按压反馈 |
| duration-base | 200ms | 阴影过渡、下拉展开、卡片抬升 |
| duration-slow | 280ms | 弹窗进出场、抽屉滑出、页面区块切换 |
| ease-standard | `cubic-bezier(0.2, 0, 0, 1)` | 默认缓动（快出缓停，无回弹） |
| ease-exit | `cubic-bezier(0.4, 0, 1, 1)` | 离场（加速消失） |

**动效编排场景规范**：

| 场景 | 规格 |
|------|------|
| 页面首载 | 内容区块 staggered reveal：卡片组依次 40ms 延迟、上移 12px→0 + 淡入（duration-slow） |
| 存栏/指标数字变化 | 数字滚动补间 600ms（超出动效令牌属数据动画，单独豁免），变化后短暂 primary-100 底色高亮 |
| 骨架屏 | shimmer 扫光 1.2s 循环，扫光色 `rgba(255,255,255,.55)` |
| 在线状态点 | 绿点 2s 周期呼吸（opacity 1→0.6→1），离线灰点静止 |
| toast | 底部滑入 200ms，停留 3s，淡出 120ms |
| 弹窗 | 遮罩淡入 + 面板 scale 0.96→1 + 淡入（duration-slow）；关闭反向用 ease-exit |
| 告警插入 | 新告警卡片从顶部滑入 + primary/warning 左缘色条闪烁 2 次 |
| 流式输出 | 打字光标 1s 闪烁；分节卡片逐节淡入 |

## 三、通用组件质感规范

- **空状态**：统一**线性插画风格**（1.5px 圆头描边、双色调：primary-200 + border 色），居中 + 一句话（text-secondary）+ 主按钮；插画全站同一族
- **加载**：卡片骨架屏（bg-subtle 底 + shimmer）；表格加载条（primary-500 顶部 2px 进度条）；AI 生成中用"呼吸点 + 文案"而非旋转 spinner
- **错误**：卡片内联提示条（danger @ 8% 底 + danger 图标 + 重试按钮）；全局 toast 只用于操作结果反馈
- **危险确认**：二次确认弹窗，正文说明后果，确认按钮红底白字；**休药期强制出栏弹窗附合规原文引用**
- **标签/徽标**：6px 圆角 + 语义色 8% 底 + 语义色深字（对比度 ≥4.5:1），禁止纯色块白字小标签
- **开关/步进器**：主色为选中态；步进器按钮 32×32、禁用置灰——数量输入一律步进器 + 键盘输入，前端拦截负数（EX-10）
- **图表质感**：折线下方 8%→0 主色渐变面积填充；柱状图圆角顶 4px；hover 显示十字准线 + 数值浮层（e2）；参考线用 chart-standard 虚线 + 端点文字标签
- **页面氛围（可选）**：首页看板顶部允许一条**极淡的自然渐变氛围带**（primary-50→bg-page，高 96px，含微弱晨光暖调 `rgba(232,162,61,.06)`），让"农业感"落在第一屏；其余页面保持纯净底色。噪点纹理（grain ≤2% 不透明度）仅限演示版视觉稿，实现默认不加
- **表单校验**：错误态输入框 danger 1.5px 描边 + danger @ 6% 底；错误提示 12px danger 文字置于字段正下方，必须给修正建议（写"请输入 11 位手机号"，不写"格式错误"）；失焦即校验、提交时全量复核并滚动定位到首个错误字段
- **下拉/日期选择**：展开面板 e2、圆角 10px、max-height 320px 内滚动；选项 hover bg-subtle，选中 primary-50 底 + primary-700 文字 + 右侧对勾；日期面板禁用日期置灰不可点
- **分页器**：右对齐，上一页/下一页 + 页码；≤7 页全展示，>7 页用省略号折叠；每页条数可选（20/50/100）
- **Tooltip**：深色底（text-primary @ 92%、圆角 8px、白字 12px），延迟 300ms 出现、移开即消；只用于补充说明，不承载必读信息
- **长列表策略**：台账等大数据量页面默认**服务端分页**（每页 20/50/100）；确有滚动诉求的场景（AI 会话历史、告警实时流）用虚拟滚动；禁止无上限一次性全量渲染

## 四、页面清单与布局规范

> 每页给出：目标 / 布局结构 / 核心交互 / 视觉要点 / 必备状态。共 13 页，导航分组：总览（看板）、生产管理（场舍/繁殖/出栏/喂食）、智能中心（AI 对话/告警/待复核）、档案（台账）、系统（设备/后台/个人中心）。

### 4.1 首次登录引导向导页

- 目标：3 步完成初始设置，转化顺畅
- 布局：全屏 bg-page 底，居中卡片（宽 560px、e1、圆角 16px），顶部步骤条（1 选物种 → 2 养殖场 → 3 圈舍），步骤条可回退；已完成步骤圆点填充主色并带对勾微动画
- 第 1 步：三个大卡片单选（猪/牛/羊），选中 primary-500 描边 1.5px + primary-50 底 + 右上角主色圆形角标 ✓（scale 0→1 弹出）；未选不可下一步
- 第 2 步：表单（名称/省市区级联选择器/详细地址），省市区选完 adcode 自动带出（只读展示，等宽数字）
- 第 3 步：品种下拉（联动物种）+ 公/母数量步进器 + 生长阶段；"跳过，稍后添加"次按钮
- 视觉要点：物种卡片内放线性动物插画，让首屏就有"生命感"；卡片 hover 抬升（2.4 节）
- 状态：省市区加载失败可手动重选

### 4.2 首页总看板

- 目标：一眼看清"有没有事、畜群状态、今天该干什么"（提醒驱动）
- 布局（自上而下）：
  1. **提醒/告警汇总条**：待处理告警数、今日待办，有内容时置顶显示，warning/danger 语义底色横幅（8% 底 + 左缘 4px 实色条），点击直达
  2. 指标卡行（4 张白卡）：总存栏（公/母拆分）、今日采食完成度、当前圈舍均温、饲料日均成本——**大数字 40px tabular-nums 是卡片唯一主角**，标签 13px text-secondary 置顶，单位 14px 弱化跟排
  3. 主体两栏：左 2/3 传感器曲线卡（Tab 切换温度/湿度/NH₃/CO₂，时间范围 24h/7d）+ 摄像头预览卡；右 1/3 最新告警列表（5 条，含状态呼吸点）+ 气象卡（未来 3 天，含数据时间标注）
- 交互：曲线 hover 十字准线 + tooltip；告警点击进详情；无设备时显示模拟数据入口提示
- 视觉要点：全站唯一允许氛围带的页面（见 2.5 组件质感"页面氛围"）；曲线渐变面积填充；数字变化滚动动画
- 状态：无告警显示"一切正常"绿呼吸点；气象不可用降级文案（EX-02）

### 4.3 养殖场 & 圈舍管理页

- 目标：场舍结构一目了然，存栏调整顺手
- 布局：左侧养殖场列表卡（可增删改）；右侧圈舍卡片网格，每卡显示：圈名、品种标签、生长阶段标签、公/母存栏大数字（tabular）、[调整存栏] [转群] [出栏登记] 快捷按钮
- 调整存栏弹窗：类型（产仔/死淘/出栏/购入/转群/手动）+ 公母增减步进器 + 备注（转群需另选目标圈舍）；提交后卡片**数字滚动刷新** + 短暂主色高亮
- 视觉要点：圈舍卡片的存栏数字采用"公·母"并排双数字排版，中间用细竖线分隔，避免两行堆叠的呆板
- 状态：无场舍引导去创建；删除走红色二次确认

### 4.4 母畜繁殖管理页

- 布局：顶部待产提醒卡片行（预产期倒计时大数字，danger/warning 递进底色）；下方母畜表格（耳标号/圈舍/胎次/状态标签/配种日期/预产期/操作）
- 状态标签色：空怀=灰 / 已配种=info 蓝 / 妊娠=primary 浅绿 / 哺乳=warning 浅橙 / 淘汰=灰划线
- 单头档案抽屉（e3）：时间线展示生命周期事件（配种→检查→分娩→断奶），节点圆点用语义色实心，连接线 1px border 色，每个节点含日期与详情
- 交互：登记入口按状态给出合法动作（空怀→登记配种；妊娠→登记分娩），非法动作置灰（EX-12 的前端表达）
- 视觉要点：预产期倒计时是本页情绪焦点——3 天内 danger 红数字 + 微脉动，其余保持静默，避免全页焦虑感

### 4.5 出栏登记页

- 布局：步骤式表单——选圈舍 → 填数量（公/母）与体重（选填）、去向（选填） → 校验结果区 → 确认
- 校验结果区：通过=绿卡（success @ 8% 底 + 对勾图标）；拦截=红卡列出 **药品名 / 末次用药日期 / 休药期剩余天数**（EX-11），下方"强制继续"灰字链接 → 承诺备注弹窗（必填）→ 红色确认按钮
- 免责/合规提示固定在卡片底部："依据《兽药管理条例》，休药期未满的畜禽严禁出栏、屠宰、销售"
- 视觉要点：拦截红卡要有"文件感"——白底红缘（danger 1.5px 描边）而非大红底，正文用表格列出三要素，庄重而非惊吓

### 4.6 喂食中心页（核心页面）

- 布局（Tab 切换四个区块）：
  1. **饲喂日历**：按天视图，每圈舍一行显示"计划量 vs 实际量"圆角进度条（实际条主色渐变、计划刻度用 border-strong 竖线标记），未登记高亮 warning；顶部"按计划一键打卡"主按钮 + 按圈批量登记弹窗
  2. **当前配方**：配方卡片做出**"菜谱卡"质感**——原料表格（名称/占比/每顿喂量，数字列 tabular 右对齐）+ 顶部大数字：每天每头成本（40px）；营养达标表（不达标 danger 红字，EX-16）+ [换个配方] 按钮 → 生成/替代方案选择弹窗（含成本对比表）；底部依据来源小字 + "AI 生成，仅供参考"
  3. **采食与增重**：两块图表卡——采食曲线（日柱状圆角顶 + 7 天均值虚线）、日增重折线（渐变面积 + 品种标准虚线 chart-standard）；右上 [称重登记] 弹窗
  4. **成本结算**：日均饲料成本卡 + 出栏批次料肉比卡
- 异常提示条：采食降 15% / 增重偏低时，区块顶部橙色提示条附"归因分析"链接（跳 AI 问诊）
- 交互：改原料价后成本即时重算；价格 >30 天显示灰色小标（EX-17）
- 视觉要点：本页是"数据密度最高的页面"，用 Tab 分区保住留白；替代配方弹窗内三套方案做成可选中卡片横排，成本差用色阶（低=绿、中=灰、高=橙）而非红绿刺激

### 4.7 设备管理页

- 布局：设备表格（名称/类型图标/来源[真实/模拟]/绑定圈舍/在线状态点/最近心跳/启停开关/操作）；[添加设备] 与 [使用模拟设备] 双入口
- 在线状态：绿点呼吸 online / 灰点 offline（含"离线 X 分钟"）
- 摄像头设备行附 [预览] 播放弹窗（WebRTC/HLS 拉流，播放器圆角 12px + e3）
- 视觉要点：类型图标统一线性族（传感器=波形、摄像头=镜头）；离线设备行 warning @ 4% 浅底微标识
- 状态：全站图标禁用混族（见 1.2 反模式）

### 4.8 告警中心页

- 布局：顶部状态筛选 Tab（未读/已读未处理/已处理，带数量角标）+ 类型筛选（传感器/气象/视觉/疫病/设备离线）；告警卡片列表：类型图标、左缘 4px 风险色条（红/橙/绿）、内容、时间（相对时间 + hover 绝对时间）、状态、[处理] 按钮
- 处理弹窗：已读（一键）；已处理（备注必填 textarea）
- 免疫/预产期提醒**不在此页**（V1.5 起）：todo 型提醒唯一归属 4.4 母畜繁殖管理页，避免同一份提醒两处展示、两处可写（历史：曾在告警中心加 todo 区，与繁殖管理重复，已下线）
- 实时性：WebSocket 新告警顶部插入（滑入动画 + 色条闪烁）+ 铃铛红点 +1
- 视觉要点：未读卡片左侧色条 + 卡片底色语义色 @ 4%；已处理卡片整体降透明度至 60%，让"未处理的"自然浮到视觉前台

### 4.9 AI 对话问诊页

- 布局：左侧会话历史列表（240px，可新建）；右侧对话区——气泡流（用户右侧 primary-100 底圆角 16px 且右下角 4px、AI 左侧白卡 e1 且左下角 4px），AI 回复分节渲染（诊断/用药/饲料建议各带图标小标题），流式打字效果 + 光标闪烁
- 图片上传预留（PRD 3.5.9，V1.1 实装）：输入区左侧相机图标按钮占位；V1.0 不显示（避免点开无功能的死交互），V1.1 放开并支持图片气泡预览；图片免责文案"图片分析不能替代执业兽医现场诊断"在文案表占位
- 结果区固定元素：风险等级标签（low 绿/mid 橙/high 红"已转交兽医复核"）、依据来源小字、**底部固定免责声明条**："本系统 AI 建议仅作辅助参考，不能替代执业兽医诊断与处方。"
- 快捷入口：从喂食中心异常提示跳入时预填上下文（"1 号圈采食下降 15%…"）
- 视觉要点：AI 分节卡片间用 12px 细间距 + 16px 小节标题图标（主色线性图标），营造"结构化报告"的可信感，而非聊天气水的松散感
- 状态：LLM 失败显示错误气泡+[重试]（EX-03）；RAG 无结果显示"知识库暂无该病症资料，建议联系执业兽医"卡片（EX-04）

### 4.10 待复核病例页（兽医角色）

- 布局：病例卡片列表，等待时长 ≥24h 置顶且 danger 1.5px 描边+"已超时 X 小时"标签（EX-05）；卡片含：原诊断摘要、风险等级、养殖场/圈舍、等待时长
- 复核弹窗：原诊断全文、[确认]（意见选填）/ [驳回修改]（意见+修改后诊断+修改后用药必填）
- 权限：非 vet 角色导航不显示此页
- 视觉要点：等待时长做成环形进度微件（24h 一圈），超时环变红——比纯文字更直观，且只此页用

### 4.11 台账查询 & 导出页

- 布局：顶部筛选条（养殖场/圈舍/类型/时间范围）+ [导出 Excel] 主按钮；表格：时间、圈舍、类型标签、摘要 + 动态扩展列（按筛选结果出现字段生成，列名中文）
- 导出反馈：loading → 成功 toast（文件下载）；大数据量显示"正在生成"
- 视觉要点：台账是"档案"，表格去掉一切装饰——无斑马纹、行 hover 才出现底色、数字列 tabular 右对齐、类型标签 6px 圆角微标，整体呈现"纸质台账数字化"的克制感
- 状态：无记录空状态；导出失败错误提示

### 4.12 后台管理页（admin）

- 布局：二级 Tab：用户 / 物种 / 细分品种 / 兽药库 / 饲料营养库 / 知识库文档
- 统一 CRUD 表格模式：搜索栏 + [新增] + 行内编辑/删除；物种编辑用 JSON 编辑器（等宽字体 + bg-subtle 底）
- 兽药库：is_forbidden 行整行 danger @ 6% 底 + 红斜标"违禁"；知识库上传记录来源与整理人必填
- 视觉要点：后台保持与前台同一设计语言但密度可更高（行高 44px），强调"效率工具"属性

### 4.13 个人中心

- 布局：简单表单卡——昵称、手机号（只读）、主物种选择（改动确认弹窗说明"历史数据保留，仅影响新建圈舍"）、修改密码（旧密码+新密码+确认）
- 保存成功绿色 toast
- 视觉要点：主物种选择复用引导页的大卡片单选组件，保持全站一致性

## 五、全局交互规则

| 规则 | 说明 |
|------|------|
| 反馈及时 | 所有写操作成功/失败都有 toast；耗时操作（导出、生成配方、AI 问诊）有 loading 态 |
| 操作可逆 | 删除类操作二次确认；存栏调整后可在台账追溯，不提供"撤销"但提供反向 manual 调整 |
| 危险操作 | 休药期强制出栏、违禁药提示、删除场舍 → 红色按钮 + 明确后果文案 |
| 数量输入 | 一律步进器 + 键盘输入，禁止负数（前端拦截 EX-10） |
| 时间 | 全站东八区，相对时间展示（"3 分钟前"）+ hover 绝对时间 |
| 响应式 | 桌面优先，逐档降级按 2.3 节断点表执行；看板与对话页在 768px 以下降级单栏 |
| 无障碍 | 正文对比度 ≥4.5:1；风险不只靠颜色区分（同时有文字标签）；按钮可键盘可达；动效遵循 `prefers-reduced-motion`（减弱动效用户直接呈现终态） |

## 七、资源与实现规范

### 7.1 图标库

- **选型定稿：Lucide**（线性、1.5px 圆头描边），与 1.2 反模式清单"图标同一族"强绑定，全站禁止混入第二族，禁止用 emoji 充当图标
- 使用规格：默认 20×20（导航 18×18、卡片标题 16×16），stroke-width 1.5，颜色跟随文字（currentColor）
- 语义映射固定并随代码维护映射表：传感器=activity（波形）、摄像头=video、告警=bell / alert-triangle、存栏=layers、繁殖=heart-handshake、喂食=utensils、台账=notebook-text、设备=cpu；Lucide 缺失的动物类图标用"圈舍+品类标签"表达，不强行凑图形

### 7.2 插画

- **全部自绘内联 SVG**，不引外部插画图库（避免风格失控与版权风险）
- 绘制规格：1.5px 圆头描边、双色调（primary-200 主体 + border 辅助）、无面部细节的极简线性风，与图标同一笔触语言
- 尺寸：空态插画 160×120，引导页物种插画 96×96；源文件统一放 `assets/illustrations/` 按页导出，禁止各页私改笔触粗细

### 7.3 字体资源

- 品牌西文 Inter 只作用于数字与英文（`tnum` 开启），中文一律系统栈；**不加载中文网络字体**（体积与渲染成本不划算）
- 加载策略：`font-display: swap` + 系统兜底，FOUT 不阻塞首屏渲染

### 7.4 平台落地映射（参考 Vue3 + Element Plus + ECharts）

| 规范项 | 落地方式 |
|--------|---------|
| 色彩/阴影/动效令牌 | CSS 变量挂 `:root`，覆写 Element Plus 主题变量 |
| 圆角/行高 | EP 组件按 2.3 节覆写（按钮 10px、表格行高 48px、标签 6px） |
| 图标 | `lucide-vue-next`，按 7.1 语义映射表引用 |
| 图表 | ECharts 自定义主题：主系列 primary-500、参考线 chart-standard 虚线、渐变面积 8%→0 |
| 等宽数字 | 全局 `.tnum` 工具类（`font-variant-numeric: tabular-nums`），数字列强制挂载 |
