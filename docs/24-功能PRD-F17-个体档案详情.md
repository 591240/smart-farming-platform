# 功能 PRD — F17 个体档案详情（一畜一档）

> 版本 V1.0 · 2026-10-14 · 依赖 F14 个体耳标档案（mock v10 / FastAPI 切真主链路）
> 定位：把个体耳标从"一行档案"升级为"像人的病历一样的完整档案"——基本信息 + 生长曲线 + 全生命周期事件时间线。

## 一、背景与依据

用户诉求：个体耳标要能写每只动物的生病、体重等信息，"各种记录像人的档案一样"。

**法规依据**（《畜禽标识和养殖档案管理办法》，农业农村部）：
- 养殖档案法定记载：品种/数量/繁殖记录/标识情况/来源和进出场日期；饲料添加剂与兽药使用；检疫、免疫、监测、消毒；**发病、诊疗、死亡和无害化处理**
- 种畜个体档案：标识编码、性别、出生日期、**父系和母系品种类型、母本标识编码（血缘）**
- 保存期限：商品猪禽 2 年、**牛 20 年、羊 10 年**、种畜禽长期；档案真实完整连续，严禁伪造篡改
- 耳标**不得重复使用**；磨损/破损换新标识须在档案记录（本系统以"换标事件"承接）

**行业标杆**（U-LITS 国家追溯系统"事件寄存器"模型；榆林湖羊基地"耳标=身份证+档案+电子病历"）：
个体档案的核心不是一堆静态字段，而是**一条全生命周期事件时间线**。

## 二、设计决策

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 数据模型 | 通用事件表 `individual_event`（event_type + payload JSONB），不按类型分表 | 学 U-LITS LER：一切个体动态都是事件，时间线天然统一，新类型零迁移 |
| 流水联动事件 | 建档/换标/转群/离栏由流水自动落事件（只增不删）；体重/免疫/诊疗/备注为手动记录（可纠错删除） | 流水事件 = 台账镜像（不可篡改）；手动事件保留纠错口 |
| 体重曲线 | 从 weight 事件 payload 提取数值序列，详情页画折线 + 相邻两点日增重 | 湖羊标杆的"生长周期可查" |
| 照片 | V1.0 不做图片上传（无文件存储基建），以"外貌特征"文字描述承接 | 遗留问题池：minio 已就位，V2.0 接 |
| 与圈级记录关系 | 圈级用药/问诊病例**不自动**挂个体（无法精确归属），个体诊疗记录手动记 | 精确性优先，圈级→个体拆分列入版本池 |

## 三、功能需求

### FR-01 档案详情聚合（GET /individual/{id}/detail）
- 返回：个体完整信息（含新增 traits 外貌特征 / lineage 血缘备注）+ 事件列表（按 event_date 降序、同日按 id 降序，上限 200）+ 体重曲线序列 `[{date, weight_kg, daily_gain}]`（相邻事件间隔天数 ≥1 时算日增重，kg/日，round2）。
- 归属校验：他人个体 40302/40401；未登录 40101。

### FR-02 手动记录事件（POST /individual/{id}/event）
四类，payload 按类型校验：
| 类型 | 必填 | 选填 |
| --- | --- | --- |
| weight 体重 | weight_kg（0<kg≤500，round2） | note |
| immunization 免疫/驱虫 | vaccine_name（≤64） | dose、next_date（下次免疫日） |
| treatment 发病/诊疗 | symptom（≤128） | diagnosis、medication、outcome、vet_name |
| note 备注 | content（≤128） | — |
- event_date 必填（yyyy-MM-dd，≤ 今天，≥ 出生日期（若已填））。
- 手动事件（仅以上四类）可纠错删除（DELETE /individual/event/{event_id}）；流水联动事件删除 → 42201"档案事件不可删除"。

### FR-03 流水联动事件（自动落，只增不删）
| 事件 | 触发 | payload |
| --- | --- | --- |
| register 建档 | 个体创建（含自动建档/补齐） | source |
| rename 换标 | 编辑耳标号且变化 | old_no / new_no（法规：换标留痕） |
| transfer 转群 | F02 转群 | from_pen / to_pen |
| exit 离栏 | 死淘/出栏/调减/淘汰 | status / note |

### FR-04 编辑扩展（PUT /individual/{id}）
- 新增可编辑字段：traits（外貌特征 ≤128）、lineage（血缘备注 ≤128，种畜记录父系母系）。

### FR-05 前端档案页（个体耳标页行点击 → 档案抽屉）
- 头部信息卡：耳标号/性别/圈舍/品种/出生日/来源/状态 + 外貌特征 + 血缘备注。
- 体重曲线：SVG 折线（最近 ≤20 个点），标注最新体重与平均日增重；空态提示"记一笔体重后生成"。
- 事件时间线：图标区分类型（建档/换标/转群/离栏/体重/免疫/诊疗/备注），流水事件带"档案"角标（不可删），手动事件可删。
- 「+记一笔」：四类型页签表单；「编辑档案」扩展外貌特征/血缘。

## 四、异常清单

| 场景 | 码 | 文案 |
| --- | --- | --- |
| 体重超界 | 42201 | 体重需在 0~500kg 之间 |
| 事件日期晚于今天 | 42201 | 事件日期不能晚于今天 |
| 早于出生日期 | 42201 | 事件日期不能早于出生日期 |
| 免疫缺疫苗名 / 诊疗缺症状 / 备注缺内容 | 42201 | 对应必填提示 |
| 删除流水联动事件 | 42201 | 档案事件不可删除 |
| 他人档案 | 40302/40401 | 同 F14 口径 |

## 五、验收切片（f17-smoke + backend 冒烟）

建档自动 register 事件 → 换标 rename 留痕 → 体重事件×3（曲线+日增重）→ 免疫/诊疗/备注 → 日期校验（晚于今天/早于出生）→ 转群 transfer 事件 → 死淘 exit 事件 → 手动事件可删/流水事件不可删 → 他人档案 40302 → F14 回归不破。

## 六、遗留（版本池）

- 个体照片上传（minio 已就位）；圈级用药/问诊病例拆分挂个体；免疫到期提醒接入 F07 提醒中心；档案导出 PDF（法规保存年限要求电子化留存的场景）。
